# «Битва знаний»

Локальная многопользовательская викторина для компании (2–8 человек). Работает **без интернета** — по локальной Wi-Fi сети.

Один человек запускает игру на Android-телефоне (ведущий), остальные заходят со своих телефонов через браузер по QR-коду или адресу — **ничего устанавливать не нужно**. Опционально игру можно выводить на телевизор (Android TV).

## Скачать

Готовые APK — в **[Releases](https://github.com/valera-freeman/bitva-znaniy-apk/releases)**:

- `BitvaZnaniy-phone-*.apk` — приложение для **телефона ведущего** (обязательно);
- `BitvaZnaniy-tv-*.apk` — приложение для **Android TV** (не обязательно).

Берите самую свежую версию (верхняя в списке).

Текущая версия: телефон **1.74**, телевизор **1.11**.

## Быстрый старт

1. Установите APK телефона на телефон ведущего.
2. Телефон ведущего и телефоны игроков — в одной Wi-Fi сети.
3. Откройте приложение → «Создать игру» → появится адрес и QR-код.
4. Игроки открывают адрес в браузере или сканируют QR — и входят в игру.
5. На телевизоре откройте TV-приложение — оно само найдёт игру.
