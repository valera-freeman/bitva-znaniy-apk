# «Битва знаний» — что нового

Сборка: телефон **1.82** (versionCode 83), телевизор **1.12** (versionCode 13).

## Режим «Одиночная игра» — «Играть одному» (1.79–1.82)

- Кнопка **«Играть одному»** на главном экране: проходите викторину в одиночку — **без сервера, без интернета и без других игроков**.
- Экран настройки: категории (по умолчанию все, «Выбрать все / Снять все»), сложность (мультивыбор), количество вопросов (5–100), подсказки «50 на 50» (по умолчанию 1). Есть «Сбросить настройки игры» — сбрасывает **только** настройки одиночного режима.
- Экран вопроса — без шкалы таймера (время не ограничено); тап по теме показывает сложность, как в локальной игре.
- Экран раскрытия — с прогрессом («Сыграно X из Y», верных/неверных) и кнопкой **«Дальше»**.
- Экран **«Игра завершена»** — процент правильных, итоги, кнопки «Сыграть ещё раз» и «В главное меню».
- Меню «…» упрощено (только «Музыка и звуки» и «Выйти из игры»); выход — модалка «Выйти из игры?» / «Прогресс текущей игры будет потерян».
- Настройки одиночной игры хранятся **отдельно** от локальной — не влияют друг на друга.
- Правки по тестам: цвета значений в прогрессе/итогах, отступы заголовков, футер финала над панелью навигации, сброс попапа сложности при уходе с вопроса.

## Полировка (1.75–1.82)

- Иконка приложения: надписи «БИТВА»/«ЗНАНИЙ» вокруг логотипа, симметрично, без обрезки.
- Исправлено: после «+60 с» и «Спросить остальных» шкала таймера не растягивается на полное значение; на ТВ таймер вопроса приостанавливается на время голосования; «Возобновить игру» — с подтверждением.
- ТВ: голосование «Спросить остальных» не показывает экран голосования игрока; раскрытие/статистика компактнее при 6–8 игроках; счётчик ставок аукциона учитывает игроков с 0 очков; «Телевизор подключён» при 6–8 игроках — сеткой; «Ожидаем игроков с добавленным временем» после «+60 с».
- ТВ: на экране «Положение игроков» счётчики верно/неверно цветные (бирюзовый/красный); нажатие «назад» — диалог подтверждения выхода; новый баннер.
- Телефон: на экране ставки видны ваши очки; в «Очках» показывается бонус за первый верный ответ.

## Вопрос-аукцион (1.68–1.75)

- Ставки очками перед аукционным вопросом (фазы: ставка → сводка → вопрос → раскрытие → статистика); настройка у хоста.
- Верхняя граница «Количество аукционов» = вопросов − 4; авто-ставка при 0 очков; фиксация последней ставки по таймауту.
- Игрок, не подтвердивший ставку, получает минимум (50 / все очки / 0) вместо 0; последнее значение слайдера гарантированно засчитывается при сворачивании.
- Пауза доступна на ставке и сводке; музыка игрока применяется локально; «Не использовать вопросы, переведённые ИИ» включено по умолчанию.

## Подсказки и помощь игрокам (круг 70–71)

- «50 на 50», «+60 с» и «Спросить остальных» с настройкой у хоста и индивидуальным использованием у игроков.
- Индивидуальные таймеры: после обычного таймера ответить/взять подсказку может только игрок с добавленным временем (+60 с).
- Одна подсказка каждого типа — раз за вопрос; счётчики выдаются на всю игру (не сбрасываются между вопросами).

## Различение устройств и надёжность (1.72–1.74)

- Игра различает устройства игроков (устойчивый отпечаток) — чужое подключение со старым id не занимает чужого игрока.
- Пауза не ломает голосование/ставку; отключившийся без «Выйти» не удерживает вопрос до конца таймера; длинные варианты при переподключении снова столбиком.

## Стабильность входа и интерфейс (1.60–1.67)

- Исправлены белые экраны при входе из приложения (серия правок); белая вспышка убрана; пинч-зум отключён.
- Настройки создаваемой игры сохраняются при перезапуске приложения.
- Звуки результата ответа (верно/неверно/нет ответа) и звуки подсказок — только при включённой музыке.
- «Фоновая музыка» переименована в «Музыка и звуки»; тайминги «Игра начинается» 8,5 с, раскрытие 7 с; после «50 на 50» +5 с на ответ.
- Модалка «О сервере» у хоста (IP, сеть, QR, статус); статус «online» после перезапуска; тост «На этом IP-адресе игра не создана».

## База вопросов (круг 61–68)

- Полная чистка базы: убраны почти-дубли, исправлены неверные ответы, устаревшие факты, опечатки.
- Добавлено 4 060 вопросов из архива «Кто хочет стать миллионером» (с факт-чеком); 2 410 вопросов перенесены в тематические категории.
- Итог: **10 735 вопросов** в 16 темах; партии без повторов даже на длинных настройках.

## Прочее (круг 40–60)

- Счётборд и сложность по тапу на экране вопроса; финал с логотипом и счётчиками верно/неверно; карточки нескольких победителей.
- «Цель игры» (по вопросам/по очкам); «Уводить в минус»; «Поздний вход»; «О сервере»; трансляция на ТВ с прекращением.
- «Фоновая музыка» плашкой в лобби; уведомления «Игра создана/идёт/завершена»; надёжнее автопереподключение и resync.
- Исправлены конкретные вопросы (ворона → стая, «марта» → «март») и прочие опечатки.
