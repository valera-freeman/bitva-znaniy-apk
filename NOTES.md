### База вопросов (10 735)
- База полностью вычищена и пополнена: полный аудит (убраны дубли с опечатками, неверные ответы, устаревшие факты) + орфографический проход нейросетью.

### Настройки игры
- По умолчанию выбраны все 16 категорий вопросов (раньше только «Общие знания»).
- У цели «Количество очков» кнопки «−100»/«+100» с откликом нажатия; на границах — тосты «Минимум 100 очков для цели игры» / «Максимум 10000 очков для цели игры».
- Модалки очков (верный / первый / нет / неверный) — настройка кнопками «−50»/«+50»; на границах диапазона — тосты «Не меньше X очков» / «Не больше Y очков».
